1. Core OOP Structure (Entregable 1 & 2)

Base Class: You are required to implement the Cliente class with basic attributes.
Encapsulation: The document specifies applying encapsulation in the development of classes and methods.
Special Methods: You must include the __str__ and __eq__ special methods.
Validations: The project requires implementing validations for attributes like email and phone.

2. Specialized Clients (Entregable 4)
Inheritance: You must implement subclases for different types of clients.
Specific Types: The PDF explicitly names the types: Cliente Regular, Cliente Premium, and Cliente Corporativo.
Code Reuse: Use of the super() method for code reuse is a mandatory technical requirement.
Polymorphism: The implementation must include overridden and polymorphic methods.

3. Technical Specifications
Python 3: The entire application must be built using Python 3.
Modular Structure: The project objective is to ensure a modular and scalable structure.
Persistence: Beyond the initial code, the document requires using SQLite for secure storage and handling JSON/CSV files.
